# Миграция цветов CRM — TangoDB Studio Controller

Документ фиксирует переход с текущей палитры (Tailwind defaults + `design_system.md`) на новую палитру **Light Theme** из гайда Studio Controller.

**Статус:** внедрено в React-приложении (миграция 2.9.81). Демо: [`tangodb/schedule-preview-new-colors.html`](../../tangodb/schedule-preview-new-colors.html).

**Источники «было»:** `.cursor/docs/ai/design_system.md`, `tangodb/src/lib/scheduleColors.ts`, `tangodb/scripts/generate-crm-colors-png.py`.

---

## Ключевое изменение подхода

| Область | Было | Станет |
|---------|------|--------|
| Блоки в сетке расписания | Сплошная заливка (`bg-indigo-600`, `bg-sky-400`, `bg-violet-600`), белый текст | Мягкий фон + цветной текст + акцентная полоска слева |
| Успех / «подтверждён» | Indigo (`indigo-50` / `indigo-600` / `indigo-700`) | Отдельный зелёный (`green-50` / `green-500` / `green-600`) |
| Бренд indigo | Холодный Tailwind (`#4f46e5`) | Тёплый Studio Controller (`#5663D6`) |

### Успех / подтверждение (green) — **новая роль**

Раньше успех шёл через indigo. В новой палитре — отдельный зелёный.

| Токен | Было | Стало (hex) | Примечание |
|-------|------|-------------|------------|
| Успех / «оплачено» / «подтверждён» | `indigo-50` + `indigo-600` / `indigo-700` | `green-50` `#ECF7F1` + `green-500` `#3F8F6B` + `green-600` `#2E7D56` | Toast success, бейдж «подтверждён», позитивные статусы |
| Toast info | `indigo-500` `#6366F1` | — **без замены в гайде** | Прежний indigo; можно оставить или выровнять под `indigo-500` → `#6B76DC` |

> **Правило design_system:** сейчас запрещены `green-*`. При внедрении новой палитры правило нужно обновить: green — только для успеха/подтверждения, не для CTA.
